# Changelog

## Unreleased

### Database migration
- **Schema version 2** (`0002_event_agent`): adds `event.agent` (`claude` or `codex`); existing records become `claude`. Run `awm doctor` once after upgrading: it writes a backup `awm.db.bak-v1` next to the database and migrates. Until then hooks show nothing and spool their captures, and other commands ask you to run `awm doctor`; `awm doctor` migrates and then ingests the spool, so nothing captured in between is lost. An older `awm` run against the migrated database skips its captures and discards any pending spool files (that binary cannot be fixed), so run `awm doctor` with the new binary before any old one can run, and keep `~/.local/bin/awm` first in `PATH`. Rollback: install the previous `awm`, close every agent session, delete `awm.db-wal` and `awm.db-shm` if present, and copy `awm.db.bak-v1` over `awm.db`.

### Changed
- **Notes carry the full earlier result**: the `found:` line shows the whole sanitised summary (up to 8,000 characters) instead of a 200-character excerpt, and a note block and a deny reason may be up to 9,500 characters (was 2,200 and 800), under Claude Code's 10,000-character `additionalContext` cap. A note that does not fit is cut to the remaining space or dropped. A shown-but-unused note costs about 2,100 tokens (8,410 characters) instead of about 150; a full block about 2,400 tokens (9,500 characters) instead of about 550.

- **WebFetch is a per-URL cache, on by default**: a fetch of a URL awm already holds is denied once and the earlier answer is handed over, whoever made the earlier fetch (the same agent, a sibling, another session or project, your other machine; never a teammate's record) within `short_circuit.window_days` (default 7 days, 1-365; was `short_circuit.window_minutes` = 30, sibling agents of the same session only, shadow). The earlier fetch must be ok, HTTP 200, not quarantined or deleted. It applies in subagents; `short_circuit.subagents` is gone, and `short_circuit.window_minutes` is replaced by `short_circuit.window_days` (a file that still has it is read as before, the key is ignored). The retry passes (once per session, agent and URL), so a new question about the page is one call away. Turn it off with `short_circuit.mode = off`.
- **A known dead URL is denied too**: a repeat fetch of a URL whose newest record is a dead end with an HTTP code of 202, 3xx or 4xx other than 429 is denied once with its own reason ("this URL returned HTTP 404 3 h ago when fetched by ...; it gave no usable content"). Timeouts and other failures without a code, 429, 5xx and refusals never deny. The newest usable record decides between this reason and the cache deny. `awm stats` adds `injections.deny_by_kind` (`cached`, `dead_url`).
- **A URL deny hands over the closest earlier answer**: when awm holds several earlier answers of the URL (WebFetch stores one per call, each answering that call's prompt), the deny hands over one: the answer that BM25 (the ranking of the search index) rates best for the current prompt, over the stored prompt, URL and the start of the answer (scored over the URL's candidates only, in Rust, with term weights (Lucene's idf) from the candidates themselves, so nothing else is read and the cost does not grow with your history), the newest on a tie or when no prompt can be compared. The first line then reads "this is the closest of N earlier answers to your prompt". A newer coded dead end still decides the dead-URL reason. No new setting.
- **The search deny has its own, stricter cutoff**: `awm calibrate` (and init, import and the capture hook's recalibration) now also stores `cutoff.query_deny`, the 75th percentile of the same top-1 scores whose median is `cutoff.query` (default 55 below 50 records). The WebSearch deny uses it; notes added after a search keep `cutoff.query`. `short_circuit.query_min_score` (0-1000, default `auto`) replaces the calibrated value with a fixed one. `awm stats` `query_deny` gains `cutoff_used` and `by_top_score`.
- **A deny does not repeat an answer you were already shown**: when the agent already received the record in an `<awm-notes>` block (from your prompt's URL, or after an earlier fetch or search) the fetch or search is still denied, but the reason names that note's ref (`awm log --ref`) instead of repeating its text (in the test, 365 instead of 1,761 characters). A subagent that never saw the note gets the full reason. `awm stats` `deny_by_kind` adds `cached_shown` and `dead_url_shown`. `scripts/verify-hooks.sh --installed` now seeds with the installed binary instead of building one.
- **Search deny filters in SQL**: the window and the teammate exclusion are applied before the per-call hit cap (`MAX_HITS`, 3), so an old record or a teammate's newer identical search no longer hides an owner's record.
- **Shadow mode is gone**: `mode` is `inject` or `off`, `short_circuit.mode` and `short_circuit.query` are `on` or `off` (both on by default), `channels.prompt_bm25` is `off` or `inject`. Old files keep working: `shadow` reads as `inject` (`mode`), `on` (`short_circuit.mode`), `off` (`short_circuit.query`, `channels.prompt_bm25`); the keys `short_circuit.subagents`, `short_circuit.window_minutes`, `short_circuit.query_window_minutes` and `inject.max_per_agent` are ignored; `awm doctor` lists each one and `awm config set` refuses them. `awm stats` no longer prints `would_have_shown`, `would_have_shown_by_channel` or `query_deny.shadow`; `awm stats --followups` adds `by_age` and `by_who` to `shown`.
- **No per-agent cap on notes**: `inject.max_per_agent` is removed (a file that still has it is read as before, the key is ignored); `inject.max_notes` still limits one injection.

### Added
- **Team sync (opt-in)**: `awm team create` starts an organisation; `awm team invite` adds members; `awm team join` accepts and prints a 6-digit code and fingerprint to compare with `awm team approve` on the inviter's machine; `awm team share` opts in projects (default unshared); `awm team unshare` withdraws; `awm team remove` evicts and rotates keys; `awm team leave` removes the caller; `delete-mine` deletes the member's records and keeps the membership. `awm sync` takes `--push-only`, `--pull-only` and `--status`. End-to-end encrypted with the server never seeing plaintext. `[team]` config keys including `team.auto_approve = none` (default: waits for manual approval), `devices` (auto-approves your own new devices), or `all` (also auto-approves member joins). `awm serve` hosts the server (SQLite or Postgres, built-in ACME TLS, `awm serve restore` and `awm serve backup`). The default build has no network code; `sync` and `serve` are feature flags.
- **Usage-limit savings**: `awm statusline` records usage-limit samples (5-hour and 7-day percentages, resets, session cost) from Claude Code's status line into `quota/` in the data directory; `awm setup --statusline` and `--remove-statusline`; `[quota]` keys `capture` and `retention_days`. `awm stats --savings` adds a quota block (estimated and proven savings as a share of the 5-hour and 7-day limits, with a cache-read range) and takes `--projects`. `awm purge --all` and `awm uninstall` delete the samples. The per-tool fallback medians of `awm stats --savings` now use only calls before the note.
- **Record web research**: Every WebSearch and WebFetch call in Claude Code (main agent and subagents) is recorded to a local SQLite database.
- **Exact URL matching**: When an agent fetches a URL you fetched before (any agent, session, project or your other machine, never a teammate's record), the earlier result is handed over in a deny, or shown with the result when the deny does not apply (precision 1.00).
- **Search by query**: When an agent searches the web or fetches a URL with a new question, search for earlier answers using BM25 full-text search (precision 0.52–0.70).
- **URL in prompt**: If you name a URL in your prompt, the tool shows any earlier research on that URL before the agent decides.
- **Note injection**: Earlier research arrives alongside the result of the new call. The only calls awm blocks are a repeated fetch of a URL it holds and a search that earlier research answers, once each; the retry passes (see the cache and search deny entries).
- **Search deny, on by default and similarity-based**: `awm hook pre-fetch` also sees WebSearch (Claude Code) and `webrun` (Codex). With `short_circuit.query = "on"` (the default) a search that earlier research matches (the BM25 match of the query channel at the calibrated deny cutoff `cutoff.query_deny`, stricter than the note cutoff, any earlier usable record including the agent's own, within `short_circuit.query_window_days`, default 7, 1-365) is denied once with up to `inject.max_notes` notes in the reason, and the retry passes. This replaces the exact token-set rule and the 3-denies-per-agent cap; `short_circuit.query_window_minutes` is ignored. `awm stats` prints a `query_deny` summary (`by_relation` gains `same_agent`) and `awm review` shows these items with their reason.
- **Subagent support**: Notes are shown to the subagent that made the call, with sibling research visible.
- **Import past research**: `awm init` extracts your research from Claude Code transcript files and imports it in seconds.
- **Redaction**: API keys, secrets, private IPs, file paths, and email addresses are redacted before storage.
- **Deletion**: `awm forget` marks records for deletion, `awm purge` removes them permanently.
- **Quarantine**: Mark records or URLs as unreliable with `awm quarantine` to keep them from being shown.
- **Search locally**: `awm search` queries your stored research without leaving your machine.
- **Review notes**: `awm review` shows you the notes your agents saw and lets you label them (saved time, relevant, irrelevant, misleading).
- **Statistics**: `awm stats` shows record counts by tool and agent, quarantined records, and injection metrics.
- **Savings estimate**: `awm stats --savings` estimates time and tokens saved by shown notes, and prints a separate upper-bound line for the page bytes the fetch summariser did not read (summariser tokens = bytes / 4; searches add 0).
- **Savings in money**: `awm stats --savings` adds a `cost` column (fetch summariser tokens at Haiku 4.5 rates plus the web search fee per avoided search) and JSON `est_cost`/`pricing`; rates are the new `[pricing]` section of `config.toml`. A subscription pays none of this per call.
- **Logging**: `awm log` shows the notes injected into your agents this session.
- **Configuration**: `awm config` lets you enable/disable channels, adjust matching thresholds, and control when notes are shown.
- **Installation verification**: `awm doctor` checks that the plugin and binary are correctly installed.
- **Report for bugs**: `awm report` generates a summary with no personal data for bug reports.
- **Plugin marketplace**: Install from a local path with `claude plugin marketplace add` and `claude plugin install`.
- **Local install script**: `bash scripts/install-local.sh` builds and installs the binary locally.
